# 全新系统安装缺陷与修订状态

2026-11-28：撤回 v0.1.0-preview 和 v0.1.1-preview。旧版只支持已有有效 PSK 的用户，不是完整从零方案。

1. “需要 32 字节二进制文件”：旧版在后端安装之前停止。PSK 是与传感器一致的 TLS 通讯密钥，不是指纹模板。同款电脑也不能共享公开密钥。
2. “fprintd 未发现设备”：前一步没有安装社区内核驱动和私有 libfprint；系统自带 fprintd 不支持该 ACPI 设备，不能依靠 lsusb 查找。
3. “无效摄像头路径”：旧版必须手填且没有自动探测。修订版枚举节点，只接受原生 GREY，按真实设备去重，唯一候选自动选择，多个候选需要选择。缺设备或权限不足仍停止。
4. “只接管自己安装的系统”：安装没完成，没有管理标记。应先完成后端安装，不应绕过保护直接改 PAM。

## 通讯配对策略

- 保留现有配对：先问是否有 Windows 以及指纹配置状态，经单独授权才尝试只读解密本机 Windows 的现有 Goodix 缓存。授权涉及的敏感文件范围和失败后的 Windows 导出步骤见 [windows-key.md](windows-key.md)。
- 手动导入：提供本人设备当前有效的 32 字节二进制文件。没有 Windows 或获取失败时适用；没有文件就停止。无通用模板。
- 已移除此前修订中的生成/上传新配对选项，不接触传感器配对状态。

读取失败不会自动重置 Windows Hello 或传感器。导出的密钥仅在本机保存，不上传。操作系统安装仍写 Linux 后端和后续经确认的 PAM 配置。

执行顺序：准备 → 后端安装及配对策略确认 → fprintd 注册设备 → 录入 → 独立验证 → 启用 PAM。后端失败后不要跳到认证启用。

上游依据：[PSK.md](https://github.com/Metrohan/gxfp5130-linux/blob/5e8c91c6b63da472dad946fbfdad2f43bca21eb4/userspace/PSK.md)。

修订版未在干净系统完成编译、硬件配对、录入、PAM、卸载全过程验收，因此暂不发布替代发行包。
